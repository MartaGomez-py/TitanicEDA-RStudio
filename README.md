# Análisis Exploratorio de Datos — Titanic

Este proyecto fue realizado durante el primer curso, en la asignatura **Introduction to Data Science**.

El objetivo consistía en realizar un **Análisis Exploratorio de Datos (EDA)** sobre el dataset del Titanic para identificar **patrones, relaciones y correlaciones** entre las características de los pasajeros y su supervivencia.

El análisis se desarrolló utilizando **R y RStudio**, aplicando técnicas básicas de exploración, análisis estadístico y visualización de datos.

## Objetivos

* Explorar y comprender la estructura del dataset.
* Analizar las principales características de los pasajeros.
* Identificar correlaciones entre variables.
* Detectar patrones asociados a la supervivencia.
* Utilizar visualizaciones para interpretar mejor los datos.

## Herramientas utilizadas

* **R**
* **RStudio**

## Análisis realizado

Se estudiaron variables como:

* Clase del pasajero
* Sexo
* Edad
* Tarifa pagada
* Relaciones familiares a bordo
* Puerto de embarque
* Supervivencia

A través de estadísticas descriptivas y diferentes visualizaciones se analizaron qué características parecían estar más relacionadas con la probabilidad de supervivencia.

## Contexto del proyecto

Este trabajo fue uno de mis primeros proyectos de análisis de datos y me permitió familiarizarme con las principales etapas de un EDA: comprender un conjunto de datos, explorar sus variables, detectar relaciones relevantes y comunicar los resultados mediante visualizaciones.
